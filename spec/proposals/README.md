# Proposals

A change that affects which files are valid, what a query returns, or the refusal codes needs a proposal.
Editorial fixes need only a pull request.

1. Copy [0000-template.md](0000-template.md) to `NNNN-short-title.md`, using the next free number.
2. Open a pull request with the proposal alone. Discussion happens on the pull request.
3. An accepted proposal is merged with status `accepted`; the specification change, its conformance cases and
   the changelog entry follow in their own pull request, which links the proposal.
4. A rejected or withdrawn proposal is merged with that status and its reasons, so the record stays.
