# Terminology lint for scripts/docs/check_docs.py.
#
# "scope:" lines list the files the lint applies to (a trailing / is a
# directory). Every other line is a denied term, a case-insensitive regular
# expression matched as a whole word outside code, then "=>" and what to
# write instead. A line containing "terms: ok" (for example in an HTML
# comment) is exempt, for quoting the term itself. The full table is in
# docs/dev/docs.md.
#
# Pages enter the scope as they are rewritten; wave 2 adds the reading and
# operating guides and the language READMEs.
